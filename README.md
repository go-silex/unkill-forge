# unkill-forge

Publish HTML artefacts at stable URLs, control who can read them, and create, read and edit them from AI agents through a remote MCP server. Runs on Cloudflare Workers, D1, R2 and KV.

**Status:** pre-release. Gate 0 (sign-in and MCP connectivity proof) is in progress; see [the specification](docs/spec.md).
