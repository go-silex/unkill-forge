# Security policy

Report vulnerabilities privately via [Report a vulnerability](https://github.com/go-silex/unkill-forge/security/advisories/new). If private reporting is unavailable, contact a repository maintainer privately before sharing details. Do not post vulnerabilities, tokens, share URLs or instance data in public issues or pull requests.

Include the affected version or commit, the expected and observed impact, and reproducible steps on your own test instance. Redact credentials and identifying data. Instance-specific exposure should also be reported to the operator of that instance.

See [security and known limits](docs/security.md) for the threat model and deployment constraints.
